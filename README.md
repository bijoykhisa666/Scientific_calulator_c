# Scientific Calculator in C

A simple scientific calculator developed using the C programming language. This project demonstrates fundamental programming concepts and mathematical calculations in C.

## 📌 Project Overview

The Scientific Calculator is a console-based application designed to perform mathematical calculations. It is a beginner-friendly project that helps demonstrate the use of functions, operators, conditional statements, and user input in C.

## ✨ Features

- Basic arithmetic operations (addition, subtraction, multiplication, and division)
- Scientific calculations, if implemented
- User-friendly console interface
- Input-based calculations
- Simple and readable C source code

> Note: The available operations depend on the functions implemented in the source code.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC or another compatible C compiler
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

Install a C compiler, such as GCC, on your computer.

### Compile the Program

Open a terminal in the project directory and run:

```bash
gcc scientific_calulator.c -o calculator
```

### Run the Program

**Windows:**

```bash
calculator.exe
```

**Linux:**

```bash
./calculator
```

## 💻 How to Use

1. Compile the source code.
2. Run the generated executable.
3. Follow the on-screen instructions.
4. Enter the required values and select an operation.
5. View the calculated result.
